画像を差し替える場合は、このフォルダーに以下のPNGファイルを置いてください。
cat.png      主人公（右向き、透過背景、表示68×48px）
mouse.png    ネズミ（右向き、透過背景、推奨34×25px）
taiyaki.png  たい焼き（透過背景、推奨28×20px）
tower.png    キャットタワー（透過背景、推奨110×145px）
画像がない場合はJavaScript内のドット絵で動きます。
表示サイズと当たり判定は固定です。左向きは自動で反転します。
猫は尻尾を含めて当たり判定より広く表示しています。
hills-background.png は城と山の背景です。横長の画像で差し替えできます。
